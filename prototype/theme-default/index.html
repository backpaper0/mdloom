mdloom Default Theme プレビュー

これは mdloom の Default Theme を検証するためのプロトタイプです。 GFM の各要素と Diagram Viewer 導線を、markserve のトーンを参考にしたパステルカラーで表示します。

見出しと段落

Document は単一の Markdown ファイルであり、変換されると Document 本文・Diagram の SVG・Theme が 1つの Output ファイルへ埋め込まれます。段落内の 強調(bold) や 強調(italic)、リンク の見え方もここで確認します。

引用

Theme は Output に適用されるフォントと CSS の組であり、変換時に --css / --font で差し替え可能です。

コードブロック

シンタックスハイライトは標準搭載され、固定テーマで表示されます。

import { renderMermaid } from "@mermaid-js/mermaid-cli";

// Document を Output へ変換する
async function convert(input: string): Promise<string> {
  const html = await renderToHtml(input);
  return html;
}
