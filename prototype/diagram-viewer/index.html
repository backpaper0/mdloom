Diagram Viewer 起動方式の試作

試したい問い: Output は外部アセットを持たない単一HTMLファイル (file:// でダブルクリックして開かれることが前提)。この制約下で、 Diagram(サムネイル)をクリックしたときに、そのSVGを別タブで開いて ブラウザ標準のズームで拡大閲覧できる、という Diagram Viewer の実現方式を 実際のブラウザで確かめる。3つの候補を用意した。
サンプル Diagram(クリックで下の候補メカニズムを試す準備ができます):

A. Blob URL + window.open

URL.createObjectURL(new Blob([svg], {type: 'image/svg+xml'})) を window.open(url, '_blank') で開く。

B. data URI を仕込んだ <a target="_blank"> をクリック

data:image/svg+xml;base64,... を href に持つ <a> 要素を生成し、programmatic に .click()。

C. window.open(data URI) 直接呼び出し

window.open('data:image/svg+xml;base64,...', '_blank') をそのまま呼ぶ。
